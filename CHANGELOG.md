# Changelog

- Initial release
- Core tile system (Tile, TileStore, tile types)
- Rigid structure finder and compiler (RigidFinder, CompiledCommand)

- Cocapn standalone chatbot integration
- Chart intelligence (depth prediction, contour reading)
- Maritime simulators (autopilot, fish sorting, chart, full trip)
- CLI for simulation and tile management
- Mesh integration with SuperInstance ecosystem
